# Orchard Doku support

Official static support and privacy pages for Orchard Doku by Guiquan Chen (cgq-source).

- Privacy: https://cgq-source.github.io/orchard-doku-support/privacy.html
- Support: https://cgq-source.github.io/orchard-doku-support/support.html
- English, Simplified Chinese, Japanese and German.
- No external assets, JavaScript, analytics, tracking cookies or forms.
- GitHub Pages publishes `main` from `/`.

Content reflects the app’s local gameplay storage, StoreKit purchases and voluntary email support. The Pure Logic support site was used as a structural reference; product-specific disclosures are written for Orchard Doku. Contact address follows the same developer’s existing support site.
